Virtual Teacher UI V3

Changes:
- One unified teacher workspace instead of separate teacher/visual cards.
- Student question stays at the bottom.
- Old status panel remains hidden but #status is preserved for app.js.
- Visual board is hidden until a visual explanation (currently mathematics) is required.
- Teacher avatar is a floating popup with left/right/center/top-right positions.
- Avatar appears while thinking/speaking and automatically disappears after interaction.
- Public JS hooks are available as window.virtualTeacherAvatar for the future 3D avatar, picture and video features.
