Phase 3 - Oral Test Configuration UI

Files:
- index.html
- app.js

This stage adds the Oral Test configuration UI only.
It does not yet start recording, generate the question bank, score answers, or save reports.

Install:
Replace the current frontend/index.html and frontend/app.js with these files.
Then run:
  docker compose up -d --build virtual-teacher
Refresh browser with Ctrl+Shift+R.

The Oral Test button appears beside Question Paper.
